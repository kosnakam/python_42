# Python for Data Science

This repository contains a collection of Python exercises and small projects completed as part of the 42 Python Piscines curriculum.

## Overview

The project is organized by topic and includes exercises covering:

- basic Python syntax and functions
- array and data manipulation
- CSV and data table processing
- object-oriented programming
- modularization and packaging

## Repository structure

```text
.
├── 00_Starting/
├── 01_Array/
├── 02_DataTable/
├── 03_OPP/
├── 04_Dod/
└── module_tmp/
```

Each folder contains exercises, test scripts, and supporting files for the corresponding topic.

## Getting started

Make sure Python 3 is installed on your machine.

```bash
python3 --version
```

You can run individual exercises directly, for example:

```bash
python3 00_Starting/ex00/Hello.py
```

Some exercises include a tester script, which can be run in the same way:

```bash
python3 00_Starting/ex02/tester.py
```

## Notes

- Many exercises are designed to be completed independently inside each topic folder.
- The repository also includes a small packaging example under module_tmp/.
- If you want to explore the package example, check the files in that directory and follow the instructions inside it.

## Learning goals

This repository is intended to practice:

- Python fundamentals
- file handling and data processing
- object-oriented design
- writing simple reusable modules
- basic packaging and project organization
